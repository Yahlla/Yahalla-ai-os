# Yahalla AI OS

A local-first AI operating system: each user runs Yahalla AI on their own device,
with its own local model, memory, knowledge, skills, and agent runtime. No
central AI server, no tunnel, no dependency on any other machine.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the full architecture,
local runtime, model management, memory/learning, security, and setup docs.

Quick start (developers): `sh scripts/setup-local.sh`
